# HEARTCALM Landing Page

Landing page statis untuk HEARTCALM Acne Water Gel, dirapikan menjadi struktur HTML, CSS, dan JavaScript terpisah.

## Struktur

- `index.html`: markup dan susunan konten halaman.
- `css/styles.css`: gaya visual khusus HEARTCALM.
- `js/main.js`: validasi formulir newsletter dan modal sukses.
- `asset/`: tempat menyimpan gambar, logo, dan aset lokal.
- `library/`: catatan library/vendor serta panduan proyek.
- `AGENTS.md`: petunjuk kerja Anti-Slop untuk sesi coding berikutnya.

## Menjalankan

Buka `index.html` di browser atau jalankan server statis lokal. Bootstrap, Bootstrap Icons, dan Google Fonts masih dimuat dari CDN, jadi koneksi internet diperlukan untuk library tersebut.

## Catatan fungsi

Form newsletter saat ini hanya melakukan validasi di browser dan menampilkan modal simulasi. Belum ada integrasi backend untuk menyimpan alamat email atau mengirim kode promo. Tautan pembelian, konsultasi, dan sosial masih perlu diarahkan ke URL resmi sebelum produksi.
