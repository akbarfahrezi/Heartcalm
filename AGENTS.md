## antislop

Untuk pekerjaan UI, copy, people, layout mobile, atau komentar kode, baca `antislop.md` (core) lalu skill yang sesuai:
- UI / visual: `skills/antislop-ui/SKILL.md`
- Copy & text: `skills/antislop-copywriting/SKILL.md`
- People: `skills/antislop-human/SKILL.md`
- Mobile / responsive: `skills/antislop-layoutmobile/SKILL.md`
- Code comments: `skills/antislop-code/SKILL.md`

Sebelum mulai, ikuti bagian "Two Usage Modes" di core Anti-Slop.
Terapkan mode DURING yang dipilih untuk sesi saat ini. Pertahankan komentar yang menjelaskan maksud kode; hapus komentar generik yang tidak menambah konteks.

## Konvensi proyek
- Pertahankan pemisahan markup, styling, dan perilaku.
- Gunakan nama variabel dan fungsi yang menjelaskan maksudnya.
- Jangan menambahkan aset, testimoni, angka, atau klaim produk seolah-olah terverifikasi tanpa sumber.
- Pastikan tautan navigasi punya tujuan nyata dan periksa penggunaan keyboard serta tampilan mobile.
